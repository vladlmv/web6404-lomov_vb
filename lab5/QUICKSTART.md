# Быстрый старт

## Шаг 1: Установите зависимости

```bash
npm install
```

## Шаг 2: Запустите два сервера в разных окнах терминала

### Окно терминала 1 - API сервер:
```bash
npm run api
```
Должно появиться сообщение, что сервер работает на http://localhost:8000

### Окно терминала 2 - Веб-сервер:
```bash
npm run dev
```
Должно появиться сообщение, что сервер работает на http://localhost:8080

## Шаг 3: Откройте сайт в браузере

Перейдите по адресу: **http://localhost:8080**

Сайт откроется с главной страницы.

## Важные моменты:

1. **Ссылки на странице mock-json-server** (`/bookings`, `/tours`) - это API эндпоинты, которые используются JavaScript кодом. Их НЕ нужно открывать в браузере напрямую.

2. **Работа эндпоинтов:**
   - Когда вы заполняете форму бронирования и нажимаете "Забронировать тур", JavaScript автоматически отправляет POST запрос к `http://localhost:8000/bookings`
   - Когда вы открываете страницу "Туры", JavaScript автоматически делает GET запрос к `http://localhost:8000/tours` для загрузки данных в таблицу

3. **Оба сервера должны работать одновременно** - не закрывайте окна терминала!
