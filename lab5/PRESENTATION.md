# Презентация модернизации проекта

## Цель модернизации

Модернизация существующего веб-сайта туристического агентства с внедрением современных технологий JavaScript для улучшения пользовательского опыта и функциональности.

---

## 1. Динамическая валидация формы бронирования

### Проблема до модернизации:
- Валидация происходила только при отправке формы
- Пользователь не получал обратную связь во время заполнения
- Отсутствовали подсказки об ошибках

### Решение:
**Создан класс `FormValidator`** с валидацией в реальном времени:

| Поле | Правила валидации | События |
|------|-------------------|---------|
| ФИО | Только русские буквы, минимум 3 символа | `input`, `blur` |
| Email | Формат email (регулярное выражение) | `input`, `blur` |
| Телефон | Минимум 10 цифр, допустимые символы | `input`, `blur` |
| Дата | Не может быть в прошлом | `change` |
| Количество | От 1 до 10 человек | `input`, `blur` |
| Тур/Размещение | Обязательный выбор | `change` |

### Результат:
✅ Подсказки появляются сразу при вводе  
✅ Визуальная индикация (зеленый/красный цвет)  
✅ Понятные сообщения об ошибках  

**Пример кода:**
```javascript
form.email.addEventListener('input', (e) => {
    const validation = validator.validateEmail(e.target.value);
    validator.showHint(e.target, validation.message, validation.valid);
});
```

## 2. Интеграция с mock-json-server

### До модернизации:
- POST запросы отправлялись на внешний сервис (httpbin.org)
- Отсутствовал контроль над серверной частью

### Решение:
**Создан файл `data.json`** с конфигурацией эндпоинтов:

```json
{
    "/bookings": {
        "post": {
            "data": {
                "success": true,
                "message": "Бронирование успешно создано"
            }
        }
    },
    "/tours": {
        "get": {
            "data": [...]
        }
    }
}
```

### Реализация POST запроса:
```javascript
const response = await fetch('http://localhost:8000/bookings', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(formData)
});
```

### Особенности:
✅ Полная валидация перед отправкой  
✅ Обработка ошибок подключения  
✅ Блокировка повторной отправки  
✅ Очистка формы после успешной отправки

## 3. Асинхронная загрузка данных туров

### Проблема до модернизации:
- Данные в таблице были статическими (захардкожены в HTML)
- Невозможно было обновить данные без перезагрузки страницы

### Решение:
**Создан класс `ToursManager`** для управления данными:

### Ключевые методы:

1. **`loadTours()`** - асинхронная загрузка:
   ```javascript
   async loadTours() {
       const response = await fetch('http://localhost:8000/tours');
       const result = await response.json();
       this.renderTours(result.data);
   }
   ```

2. **`renderTours()`** - динамическое заполнение таблицы:
   - Очистка существующих строк
   - Создание новых элементов `<tr>`
   - Экранирование HTML для безопасности (защита от XSS)

3. **Обработка ошибок**:
   ```javascript
   try {
       // загрузка данных
   } catch (error) {
       this.showError(`Ошибка: ${error.message}`);
       this.renderFallbackTours(); // резервные данные
   }
   ```

### Результат:
✅ Таблица заполняется динамически с сервера  
✅ Обработка всех возможных ошибок  
✅ Индикаторы загрузки и состояния  
✅ Резервное отображение данных при недоступности сервера

## 4. Периодическое обновление данных

### Требование:
Обновление данных каждые 5 минут

### Реализация:

```javascript
startPeriodicUpdate() {
    this.intervalId = setInterval(() => {
        this.loadTours();
    }, 5 * 60 * 1000); // 5 минут
}
```

### Особенности:
✅ Автоматический запуск при загрузке страницы  
✅ Отображение времени последнего обновления  
✅ Остановка при уходе со страницы (оптимизация ресурсов)  

**Событие очистки:**
```javascript
window.addEventListener('beforeunload', () => {
    toursManager.stopPeriodicUpdate();
});
```
