## 1. Динамическая валидация данных формы в процессе ввода

### Что было реализовано:

**Файл: `booking.js`**

- Создан класс `FormValidator` для управления валидацией всех полей формы
- Реализована валидация в реальном времени с использованием событий `input`, `blur`, `change`

### Детали реализации:

1. **Валидация ФИО** (`validateName`):
   - Проверка на непустое значение
   - Минимальная длина 3 символа
   - Проверка на наличие только букв русского алфавита (регулярное выражение: `/^[А-Яа-яЁё\s-]+$/`)

2. **Валидация Email** (`validateEmail`):
   - Проверка формата email через регулярное выражение: `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`

3. **Валидация телефона** (`validatePhone`):
   - Проверка допустимых символов (цифры, пробелы, `+`, `-`, `(`, `)`)
   - Проверка минимального количества цифр (10)

4. **Валидация даты** (`validateDate`):
   - Проверка, что дата не в прошлом
   - Установка минимальной даты через атрибут `min` поля ввода

5. **Валидация количества человек** (`validatePeople`):
   - Проверка диапазона от 1 до 10

6. **Валидация выбора тура и типа размещения**:
   - Проверка на выбор значения

### Отображение подсказок:

- Создаются динамические элементы `<div class="form-hint">` под каждым полем
- Подсказки отображаются в двух состояниях:
  - `hint-valid` (зеленый) - для корректных данных
  - `hint-invalid` (красный) - для ошибок
- Визуальная индикация полей через классы `input-valid` / `input-invalid`
- Анимация появления подсказок через CSS `@keyframes fadeIn`

**Файл: `style.css`** - добавлены стили:
```css
.form-hint { ... }
.hint-valid { ... }
.hint-invalid { ... }
.input-valid { border-color: var(--secondary); }
.input-invalid { border-color: #e74c3c; }
```

## 3. Асинхронный запрос для получения данных с обработкой ошибок

### Что было реализовано:

**Файл: `tours.js`** - создан новый класс `ToursManager`

### Функциональность:

1. **Асинхронная загрузка данных туров**:
   - GET запрос к `http://localhost:8000/tours`
   - Динамическое заполнение таблицы `<tbody>` элементами строк

2. **Обработка ошибок**:
   - `try-catch` блок для перехвата ошибок
   - Проверка статуса ответа (`response.ok`)
   - Проверка структуры данных от сервера
   - Отображение сообщений об ошибках пользователю через `.error-message`
   - Резервное отображение статических данных при недоступности сервера (`renderFallbackTours`)

3. **Индикаторы состояния**:
   - Индикатор загрузки (`.loading-indicator`) во время запроса
   - Сообщения об ошибках с понятным текстом
   - Информация о времени последнего обновления

### Детали реализации:

```javascript
async loadTours() {
    try {
        this.showLoading();
        const response = await fetch(this.apiUrl, {...});
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        const result = await response.json();
        this.renderTours(result.data);
    } catch (error) {
        this.showError(`Ошибка загрузки данных: ${error.message}`);
        this.renderFallbackTours();
    }
}
```

**Файл: `data.json`** - создан эндпоинт для GET запросов:
```json
"/tours": {
    "get": {
        "data": [
            {"id": 1, "destination": "Турция", ...},
            ...
        ]
    }
}
```

**Файл: `tours.html`**:
- Добавлен `id="toursTable"` для таблицы
- Обернут в контейнер `.tours-table-container`
- Подключен скрипт `tours.js`

## 4. Периодическое обновление данных (каждые 5 минут)

### Что было реализовано:

**Файл: `tours.js`**

- Использование `setInterval()` для периодических запросов
- Интервал: 5 минут = `5 * 60 * 1000` миллисекунд
- Автоматический запуск при загрузке страницы через метод `startPeriodicUpdate()`
- Остановка интервала при уходе со страницы через событие `beforeunload`

### Детали реализации:

```javascript
this.updateInterval = 5 * 60 * 1000; // 5 минут

startPeriodicUpdate() {
    this.intervalId = setInterval(() => {
        console.log('Периодическое обновление данных о турах...');
        this.loadTours();
    }, this.updateInterval);
}

stopPeriodicUpdate() {
    if (this.intervalId) {
        clearInterval(this.intervalId);
        this.intervalId = null;
    }
}
```

- Отображение времени последнего обновления в элементе `.refresh-info`
- Информация о следующем обновлении через 5 минут
