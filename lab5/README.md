# Проект "Путешествуй с нами"

Веб-сайт туристического агентства с динамической валидацией форм и асинхронной загрузкой данных.

## Требования

- Node.js и NPM (установлены вместе)

## Быстрая установка зависимостей

```bash
npm install
```

Это установит необходимые пакеты (mock-json-server и http-server).

## Установка и запуск

**ВАЖНО:** Для работы сайта нужно запустить **два сервера одновременно**:
1. **API сервер** (mock-json-server) на порту 8000 - для обработки запросов
2. **Веб-сервер** для статических файлов (HTML, CSS, JS) - для отображения сайта

### 1. Запуск API сервера (первое окно терминала)

Запустите mock-json-server (оставьте его работать):
```bash
# Если установлены зависимости через npm install
npm run api

# Или напрямую
npx mock-json-server data.json
```

Сервер будет доступен по адресу: `http://localhost:8000`

**Примечание:** Ссылки на странице mock-json-server (`/bookings`, `/tours`) - это API эндпоинты. Их не нужно открывать в браузере напрямую - они используются JavaScript кодом для получения и отправки данных.

### 2. Запуск веб-сайта (второе окно терминала)

Откройте **новое окно терминала** в той же папке и запустите веб-сервер:

```bash
# Если установлены зависимости через npm install
npm run dev

# Или используя Python
python -m http.server 8080

# Или напрямую через npx
npx http-server -p 8080
```

### 3. Открытие сайта в браузере

После запуска обоих серверов откройте в браузере:
```
http://localhost:8080
```

Сайт откроется с главной страницы (`index.html`).

### Итоговая структура запуска:

```
Терминал 1: npm run api (или npx mock-json-server data.json)
            → API сервер на http://localhost:8000

Терминал 2: npm run dev (или python -m http.server 8080)
            → Веб-сервер на http://localhost:8080

Браузер:    http://localhost:8080
            → Открывает главную страницу (index.html)
```

**Важно:** 
- Ссылки на странице mock-json-server (`/bookings`, `/tours`) - это API эндпоинты
- Их **не нужно** открывать в браузере напрямую - они работают через JavaScript запросы
- Когда вы заполняете форму бронирования, JavaScript автоматически отправляет POST запрос к `/bookings`
- Когда вы открываете страницу туров, JavaScript автоматически делает GET запрос к `/tours`

## Функциональность

### Динамическая валидация форм

На странице бронирования (`booking.html`) реализована валидация в реальном времени:
- Проверка ФИО (только русские буквы, минимум 3 символа)
- Проверка email (формат email)
- Проверка телефона (минимум 10 цифр)
- Проверка даты (не может быть в прошлом)
- Проверка количества человек (от 1 до 10)
- Валидация выбора тура и типа размещения

Все поля показывают текстовые подсказки в процессе ввода.

### Асинхронная загрузка данных

На странице туров (`tours.html`) таблица с турами загружается асинхронно с сервера:
- GET запрос к `/tours` эндпоинту
- Обработка ошибок подключения
- Автоматическое обновление данных каждые 5 минут
- Индикатор загрузки и сообщения об ошибках

### Отправка данных формы

Форма бронирования отправляет данные на сервер:
- POST запрос к `/bookings` эндпоинту
- Валидация всех полей перед отправкой
- Обработка ошибок отправки

## API Endpoints

### GET /tours
Возвращает список туров с информацией о направлении, продолжительности, цене, питании и рейтинге.

### POST /bookings
Принимает данные бронирования и возвращает подтверждение.
